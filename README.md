# Instagram E-commerce AI Agent

An advanced multimodal AI automation project built using n8n to demonstrate intelligent Instagram customer support, product recommendations, and order management.

## Features

- AI-powered Instagram customer conversations
- Product knowledge retrieval using RAG
- Voice message transcription
- Image understanding using AI vision
- Conversational memory
- Automated product recommendations
- Order creation, retrieval, and updates
- Google Sheets integration
- Payment screenshot analysis

## Technologies

n8n, OpenAI, REST APIs, Webhooks, Vector Search, Google Sheets, Gmail.

## Architecture

Instagram Message → Webhook → Input Processing → AI Agent → Product Knowledge Retrieval → Order Management → Customer Response

## Project Status

This is a prototype/demo project developed for learning, testing, and demonstrating end-to-end AI automation capabilities. It is not currently running as a production service.

## Security

API credentials, access tokens, and sensitive customer information are not included in the public repository.
